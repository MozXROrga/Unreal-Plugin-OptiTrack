# MoxOptiTrack Quickstart

1. Enable MoxOptiTrack and the required Live Link/OptiTrack project integration.
2. Configure the source in project-specific configuration.
3. Start the source and confirm that a Live Link subject is visible.
4. In Blueprint, retrieve MoxOptiTrackSubsystem and query that subject.

**Verification:** the subsystem returns data for the selected supported subject.

**Common issue:** v3.0.0 does not create a source from MozConfig.ini; configuration alone cannot replace the project’s Live Link setup.
